Tweakr23 - local Windows tune-up panel

1. Keep Tweakr23.bat, Tweakr23.ps1 and ui.html together in one folder.
2. Right-click the zip > Properties > Unblock (before extracting) so Windows does not flag the scripts.
3. Double-click Tweakr23.bat and accept the admin prompt.
4. The panel opens in its own window. The black console window is the engine; closing it (or pressing Quit) stops everything.

Tip: press "Restore point" in the top bar before making a lot of changes.
Nothing runs in the background, nothing is installed, and nothing is sent anywhere.
